# Water Level Controller PCB

# Overview

This project is a prototype PCB developed for a water level controller application. The main objective of this project was to learn and practice the complete PCB development process, from circuit selection and PCB design to manual fabrication and assembly.

# Project Objectives

* Understand basic electronic circuits.
* Learn PCB layout design.
* Gain experience in manual PCB fabrication.
* Practice component soldering and assembly.

# Skills Demonstrated

* Circuit interpretation
* PCB layout design
* Manual PCB fabrication
* Through-hole soldering
* Hardware prototyping

# Tools Used

* PCB design software
* Chemical etching process
* Soldering tools

# Project Status

Prototype completed.
The PCB was successfully designed and fabricated manually for learning purposes. This project served as a practical exercise in PCB design and manufacturing, and no further debugging or development was carried out.
